# docs/design — product briefs and specs

Reference material about **what** we are building. Settled documents are not rewritten; changes are new versions or new rows in `/DECISIONS.md`.

| File | What it is |
|---|---|
| `AUDIT-SUMMARY.md` | Plain-language summary of the v1.1 portability audit and the v1.2 review fixes (R1–R12). |
| `PI-icons-handoff.md` | Handoff for a separate "Icons" session: build the A3.1 icon system (PI.1–PI.3), then swap the temporary icons. Open the chat with: "Read `docs/design/PI-icons-handoff.md` and start PI.1." |
| `mobile-viewer-rules.md` | Rules MV-1…MV-48 for the mobile viewer (A4, Phase 17), to follow when it is built. Not being built now. |

Where the other briefs live:
- `/PRD.md`, `/CLAUDE.md`, `/text-to-cad-project-memory.md`, `/fine-tuning-guide.md` stay in the project root, because PRD §0.1 and `CLAUDE.md` refer to them there.
- `/design/` (top level) is the **look** of the UI: founder screenshots and `DESIGN.md` from P2.1. This folder is the **product** design.

Later specs that don't fit the PRD (for example rule-pack sources for BBMP, the office layer standard for P7.1) go here.
